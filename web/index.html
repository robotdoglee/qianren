怎么用

  1. 选模式，写一句话（想法或问题）；也可以导入自己的 RIS / BibTeX / EndNote / NoteExpress / RefWorks 文献，导入只在本机解析。
  2. 看进度：多源并行检索 → 去重排序 → 逐篇抽取 7 个字段；医学检索自动加 Europe PMC，计算机检索自动加 DBLP；填入自带凭证时再追加对应来源。
  3. 读结果：方法簇、空白点、可排序对比矩阵，导出 Markdown / CSV / BibTeX 带去组会。
  4. 高相关论文不足 3 篇时会自动、也可随时点「拓展到书籍与社区」：补充 Open Library / Google Books / 维基百科 / GitHub / Hugging Face / Stack Exchange / Hacker News / dev.to 的线索，均标「未经同行评审」。有 Qwen 时生成带 [P#] / [R#] 引用的综合解答；无 key 只列资源、不生成。

三种运行方式

  • 一键演示：预计算结果即时渲染，不需要任何 key。
  • 免 key 实时模式（默认）：浏览器直连开放 API，用规则抽取字段；Crossref、DBLP 等无 CORS 的来源经同源函数代理。
  • Qwen 增强模式：同源函数已配置密钥时自动使用；否则在设置里填你自己的 DashScope key，它只保存在你的浏览器本地，可随时清除。

抽取只依据标题与摘要，找不到依据的字段一律写「摘要未提及」，不做任何补全。

文献数据来自 OpenAlex（CC0）、 Semantic Scholar（S2 API License，需署名）、 Crossref（元数据基本公有领域）、 Europe PMC（元数据开放，需署名）、 DBLP（CC0）、 arXiv， 开放获取链接来自 Unpaywall（CC0）。 「论文之外」来自 Open Library、 Google Books、 Wikipedia、 GitHub、 Hugging Face、 Stack Exchange、 Hacker News、 dev.to。

Thank you to arXiv for use of its open access interoperability. 各来源仅通过官方公开 API 访问，遵守其条款与限流。论文之外的资源未经同行评审，只作线索。

可选的自带凭证来源（Scopus / IEEE Xplore / Springer Nature / CORE / SerpApi）只在你填写自己的 key 后启用，key 仅存本机 localStorage 并经同源函数转发；本站不登录、不注入 Cookie、不抓取谷歌学术或知网。文献导入在浏览器本地解析，文件不会上传。
