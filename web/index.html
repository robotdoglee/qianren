这个想法，前人做过吗？

一句话，查清前人做过什么、还空着什么。

OpenAlex · arXiv · Semantic Scholar 并行检索 · 免 key · ⌘/Ctrl + Enter

怎么用

  1. 选模式，写一句话（想法或问题）。
  2. 看进度：三源并行检索 → 去重排序 → 逐篇抽取 7 个字段。
  3. 读结果：方法簇、空白点、可排序对比矩阵，导出 Markdown / CSV / BibTeX 带去组会。

三种运行方式

  • 一键演示：预计算结果即时渲染，不需要任何 key。
  • 免 key 实时模式（默认）：浏览器直连三个开放 API，用规则抽取字段。
  • Qwen 增强模式：同源函数已配置密钥时自动使用；否则在设置里填你自己的 DashScope key，它只保存在你的浏览器本地，可随时清除。

抽取只依据标题与摘要，找不到依据的字段一律写「摘要未提及」，不做任何补全。

文献数据来自 OpenAlex、 arXiv、 Semantic Scholar（免费开放 API）。 Thank you to arXiv for use of its open access interoperability.

使用 Qoder 构建，部署于 Qoder Sites。

免责声明：字段抽取基于论文标题与摘要，可能不完整或有偏差，请以原文为准；检索结果受各 API 覆盖范围与限流影响。

设置

key 只保存在你的浏览器 localStorage，本站不收集、不转发；清除浏览器数据即失效。
